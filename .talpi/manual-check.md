# 수동 검수 체크리스트 (사람 눈으로 보는 마지막 패스)

준비: `bun run preview` 실행 후 브라우저에서 `http://localhost:4173` 접속.
(dev 서버로 봐도 되지만, 빌드 산출물 기준 검수는 preview가 진실.)

## 1. 홈 — 방울 씬 (데스크톱)

- [ ] 홈 접속 시 우주 배경(어두운 배경 + 성운) 위로 방울들이 떠다닌다.
      백지/검은 화면 없음, 콘솔 에러 없음 (DevTools Console 확인).
- [ ] 제목 + 태그라인("고요한 우주를 떠도는 방울들")이 보이고,
      잠시 뒤 하단에 힌트("방울을 톡, 터뜨려 보세요")가 페이드 인.
- [ ] **호버 → 정지 + 확대**: 아무 방울에나 마우스를 올리면 그 방울만
      멈추고 살짝 커진다. 커서가 pointer로 바뀐다.
- [ ] **작품 방울 오브제 공개**: 자판기 작품 방울에 호버하면 방울 안에
      자판기 오브제 이미지가 페이드/스케일 인으로 보인다.
      장식 방울은 호버해도 빈 채로 같은 반응(정지+확대)만 한다.
- [ ] **호버 해제 → 원복**: 커서를 떼면 오브제가 사라지고, 멈춘 자리에서
      순간이동 없이 다시 부드럽게 흘러간다.
- [ ] **작품 방울 클릭 → 터짐 → 이동**: 자판기 방울 클릭 시 무지갯빛
      파티클로 터지고, 터지는 연출 중에 `/works/vending-machine`으로
      전환된다 (연출이 뚝 끊기지 않고 자연스러운지).
- [ ] **장식 방울 클릭**: 터지기만 하고 이동 없음. 몇 초 뒤 화면 아래에서
      새 방울이 리스폰해 필드가 비지 않는다.
- [ ] 겹친 방울에 호버/클릭하면 앞의 방울 하나만 반응한다.
- [ ] 브라우저 창 리사이즈 후에도 방울 배치가 화면 안에서 자연스럽다.

## 2. 작품 페이지

- [ ] `/works/vending-machine` 도착 시 페이지가 페이드 인.
- [ ] 홈으로 가는 링크("← 방울들에게로")가 있고, 누르면 홈으로 돌아가며
      방울 씬이 정상 복귀한다.
- [ ] 주소창에 `/works/vending-machine` 직접 입력(딥링크)해도 페이지가
      뜬다. `/works/없는-slug`, `/아무거나`는 홈으로 리다이렉트.

## 3. 모바일 (실기기 또는 DevTools 디바이스 모드 터치 에뮬레이션)

- [ ] **길게 누르기(≥250ms) = 호버**: 작품 방울을 길게 누르고 있으면
      정지+확대+오브제. 손가락을 떼면 원복하고 **터지지 않는다**.
- [ ] **짧은 탭(<250ms) = 터뜨리기**: 작품 방울을 짧게 탭하면 터지고
      작품 페이지로 이동. 장식 방울 탭은 터지기만.
- [ ] 탭 직후 뒤에 있던 다른 방울이 유령 클릭으로 터지지 않는다.
- [ ] 누른 채 방울 밖으로 드래그하거나 스크롤 제스처가 끼어들면
      (pointercancel) 방울이 조용히 원복한다. 팝 없음.
- [ ] 씬 위에서 페이지가 의도치 않게 스크롤/줌 되지 않는다.

## 4. WebGL 차단 폴백 (B4)

방법 (하나 선택):
- Chrome: `chrome://settings` → 시스템 → "그래픽 가속 사용" 끄고 재시작,
  또는 실행 시 플래그 `--disable-webgl --disable-webgl2`.
- Firefox: `about:config` → `webgl.disabled` = true.

- [ ] WebGL 차단 상태로 홈 접속 → 백지가 아니라 배경 이미지 + 사이트
      제목 + 작품 텍스트 링크 목록("자판기" 링크)이 보인다.
- [ ] 그 링크로 작품 페이지 진입/홈 복귀가 된다.
- [ ] (선택, 실행 중 상실) DevTools Console에서
      `document.querySelector('canvas').getContext('webgl2').getExtension('WEBGL_lose_context').loseContext()`
      실행 → 씬이 폴백 화면으로 전환된다.
      (webgl2가 null이면 'webgl'로 시도.)
- 검수 후 브라우저 설정/플래그 원복 잊지 말 것.

## 5. 에러 바운더리 (작품 페이지 크래시)

방법: `src/works/vending-machine/` 페이지 컴포넌트 렌더 첫 줄에
임시로 `throw new Error('boom')`을 넣고 dev 서버(5173)로 확인.

- [ ] `/works/vending-machine` 접속 시 백지가 아니라
      "이 방울은 잠시 쉬고 있어요." + 홈 링크 최소 화면이 보인다.
- [ ] 홈 링크로 돌아가면 방울 씬은 멀쩡하다 (씬은 바운더리 밖 — 영향 없음).
- [ ] **확인 후 throw 라인 반드시 제거**하고 테스트/빌드 재확인.

## 6. 작품 목록 — 슬라이드 (페이즈 1)

씬이 뜨는 상태(WebGL 정상)에서 본다. 이 항목들은 jsdom 이 씬을 띄울 수 없어
자동으로 확인할 수 없다.

- [ ] 홈 오른쪽 위에 목록을 여는 아이콘(방울 세 개)이 보이고, 마우스를
      올리면 무엇을 여는 물건인지 알 수 있다.
- [ ] 아이콘을 누르면 주소가 `/works` 로 바뀌고 슬라이드가 오른쪽에서 열린다.
      열려 있는 동안 아이콘과 씬 힌트는 사라진다.
- [ ] 슬라이드 안에 자판기 작품이 오브제 이미지·제목·한 줄 소개와 함께 있고,
      항목을 누르면 작품 페이지로 간다. 가운데 버튼으로 새 탭에 열리고 링크
      주소를 복사할 수 있다.
- [ ] **뒤 씬이 잠긴다**: 슬라이드가 열린 동안 뒤의 방울에 마우스를 올려도
      멈추거나 커지지 않고, 클릭해도 터지지 않는다. 방울은 계속 떠다닌다.
- [ ] **바깥 클릭으로 닫힌다**: 슬라이드 바깥(왼쪽 씬 영역)을 클릭하면 목록이
      닫히고, 뒤의 씬이 다시 마우스에 반응하며, 초점이 아이콘으로 돌아간다.
- [ ] **씬이 다시 뜨지 않는다**: 목록을 열고 닫기를 서너 번 반복해도 방울이
      처음부터 다시 떠오르지 않고 하던 움직임을 이어간다. DevTools Console 에
      three.js 재초기화 로그나 에러가 없다.
- [ ] **히스토리**: 아이콘으로 연 뒤 브라우저 뒤로가기 한 번에 목록이 닫히고
      `/` 로 돌아간다. 바깥 클릭으로 닫은 뒤 뒤로가기를 누르면 사이트 밖으로
      나가지 않는다.
- [ ] **딥링크**: 주소창에 `/works` 를 직접 입력해도 같은 슬라이드가 뜬다.
      그 상태에서 바깥을 클릭해 닫으면 사이트 밖으로 튕겨 나가지 않고 홈에
      머문다.
- [ ] **좁은 화면**: 브라우저 창을 좁히면 슬라이드가 화면을 가득 덮어 바깥이
      남지 않는다. 이때 목록을 닫을 방법이 뒤로가기뿐인 것이 받아들일 만한지
      본다. (페이즈 1 보고의 질문 항목)
- [ ] **움직임 축소**: OS 설정에서 "동작 줄이기"를 켠 뒤 목록을 열면 슬라이드가
      미끄러지지 않고 즉시 나타난다.
- [ ] **색 대비**: 목록 카드의 제목과 한 줄 소개가 배경 위에서 읽을 만하다.
      오브제 이미지가 없는 자리(이미지 로드 실패)도 빈 구멍처럼 보이지 않는다.

## 7. 네트워크 셀프호스트 확인 (눈으로 한 번 더)

- [ ] DevTools Network 탭 열고 홈 → 호버 → 터뜨리기 → 작품 페이지까지
      한 바퀴. 요청 도메인이 전부 `localhost:4173`뿐인지 확인
      (폰트/스크립트/이미지 외부 도메인 0건).
