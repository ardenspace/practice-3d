# Plan: practice-3d — 비눗방울 오브제 포트폴리오

## Phase 1: 뼈대 사이트 — 등록부·에셋·라우팅

홈(배경+제목+작품 텍스트 링크)과 `/works/vending-machine` 페이지를 브라우저에서 오가며 볼 수 있다 (아직 방울 씬 없음).

Contracts: B1, B2, B3

- [x] Vite + React + TS 프로젝트 스캐폴드 (bun, react-router, R3F 의존성 포함) + Vitest 셋업. dev 서버는 기본 5173 사용 (머신 점유 포트 8080/8000/8081/5000/7000 회피).
- [x] B1·B2·B3 계약을 실패하는 테스트로 핀. B1의 "항목 N개 → 작품 방울 N개" 씬 보장은 등록부→방울 목록 파생 모듈 수준에서 핀한다 (early-pull: 이 단계에서 파생 모듈의 스텁이 생기고, 씬은 Phase 2에서 이 목록을 그대로 소비하는지 확인만 한다). B3 딥링크는 `vite preview` 환경 기준.
- [x] 에셋 준비: `renders/backdrop.png` → `public/backdrop.webp` 변환, `blender/vending-machine.blend`에서 정사각·투명 배경 오브제 이미지 렌더 → `public/works/vending-machine/` (Blender 백그라운드 렌더).
- [x] 등록부 모듈 + 자판기 항목 구현 (B1 스키마: slug/title/blurb/object/Page) + 방울 목록 파생 모듈 완성.
- [x] 라우터 + 홈 임시 화면(배경+사이트 제목+작품 텍스트 링크) + `/works/<slug>` 페이지 셸(제목·blurb·오브제 이미지·홈 링크 — 자판기 v1 최소 구성) + 알 수 없는 경로 → 홈 리다이렉트.

## Phase 2: 방울 씬 — 호버·터짐 (데스크톱)

홈에서 방울들이 우주 배경 위를 떠다니고, 호버로 정지+오브제 공개, 클릭으로 터짐(작품 방울은 페이지 이동)까지 데스크톱 핵심 경험이 동작한다.

Contracts: B4

- [x] B4 계약을 실패하는 테스트로 핀: WebGL 차단 환경에서 로드 시 배경+제목+등록된 모든 작품의 텍스트 링크가 보인다 (Phase 1의 홈 임시 화면을 폴백 화면으로 재사용).
- [ ] R3F 캔버스 셋업 + WebGL 컨텍스트 생성 실패 시 폴백 전환 (B4 통과) + 우주 배경 표시.
- [ ] 방울 필드: 등록부 파생 목록을 소비해 작품 방울 N개 + 장식 방울 배치, 떠다니는 모션 (속도·흔들림·리스폰·재질·`bubbles.glb` 사용 여부는 위임 범위 내 재량).
- [ ] 호버 인터랙션: 방울 정지+확대, 작품 방울은 오브제 이미지 공개, 장식 방울은 빈 채로 같은 반응, 해제 시 원복.
- [ ] 클릭: 터짐 파티클 연출 → 작품 방울은 `/works/<slug>` 이동, 장식 방울은 터지기만 (리스폰은 재량).

## Phase 3: 모바일 + 마감

폰에서 길게 누르기=호버, 짧은 탭=터뜨리기가 동작하고, 홈 타이포·페이지 전환·에러 바운더리 마감이 붙는다.

Contracts:

- [ ] 탭/길게 누르기 입력 처리: 단일 임계값 상수(기본 250ms) 기준으로 미만=탭(터뜨리기), 이상=길게 누르기(호버와 동일: 누르는 동안 정지+오브제, 떼면 원복).
- [ ] 홈 타이포그래피·카피 + 페이지 전환 연출 + 작품 페이지 에러 바운더리(크래시 시 홈 링크 있는 최소 화면).
- [ ] 마감 검수 패스: 스모크 시나리오 데스크톱/모바일 확인, `vite preview` 딥링크 확인, 빌드 산출물이 정적 파일만으로 동작하고 런타임 외부 요청 없음 확인.
